## APRENDIZADO

**Princípio DRY (Don't Repeat Yourself):**
- Cada conceito deve ter UMA definição autoritativa
- Redundância gera inconsistência
- Modularidade != Fragmentação

**Hierarquia de Arquivos:**
1. Principal: Completo e autoritativo
2. Core: Subset essencial
3. Memory: Aprendizados evolutivos
