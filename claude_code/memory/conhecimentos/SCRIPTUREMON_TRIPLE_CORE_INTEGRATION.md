## UPDATES & EVOLUTIONS

### 🔥 Update 03/10/2025 05:36 - CRITICAL BUG FIX: Core 2 Keyword Mapping

**Commit:** 163ff17
**Priority:** 🔥🔥🔥 CRÍTICA
**Impact:** Core 2 completamente quebrado → Totalmente funcional

#### O Bug Crítico

Core 2 (Example Finder) estava mapeando recomendações de diálogo **incorretamente** para problemas de estrutura:

```python
# PROBLEMA DETECTADO:
Input: "Have characters talk around issues instead of stating them directly"
       ↓ (mapeamento)
Output: "Three-act structure problems" ❌

# ESPERADO:
Output: "Lacking subtext in dialogue" ✅
```

**Impacto devastador:**
- Apenas 3 exemplos encontrados (vs 49 esperados)
- 100% dos exemplos eram IRRELEVANTES (estrutura em vez de diálogo)
- Sistema quebrado para qualquer análise de diálogo

#### Root Cause Analysis

O método `_extract_problems()` tinha detecção de keywords **excessivamente limitada**:

```python
# ANTES (bugado):
if 'subtext' in rec.lower():  # ❌ Só palavra literal
    problems.append({'title': 'Lacking subtext in dialogue'})

# Recomendação real do DrDialogue:
"Have characters talk around issues instead of stating them directly"
# ↑ Não contém "subtext" literal → Não detectado → Fallback errado
```

**Palavras perdidas:**
- "talk around" → indicador de subtext
- "stating directly" → indicador de subtext
- "hide feelings" → indicador de subtext
- "on-the-nose" → problema específico de diálogo
- "exposition dumps" → problema específico
- etc.

#### A Solução

**Expansão de keywords para 6 tipos de problemas de diálogo:**

```python
# DEPOIS (corrigido):
elif ('subtext' in rec.lower() or
      'talk around' in rec.lower() or
      'stating' in rec.lower() or
      'directly' in rec.lower() or
      'hide' in rec.lower() or
      'layers' in rec.lower()):
    problems.append({
        'rule_id': 'SUBTEXT',
        'title': 'Lacking subtext in dialogue',
        'severity': 'high'
    })
```

**6 mapeamentos adicionados:**
1. **SUBTEXT** (expandido): 'talk around', 'stating', 'directly', 'hide', 'layers'
2. **ON_THE_NOSE** (novo): 'on-the-nose', 'on the nose'
3. **EXPOSITION** (novo): 'exposition', 'explaining'
4. **RHYTHM** (novo): 'rhythm', 'natural', 'speech pattern'
5. **CONFLICT** (novo): 'conflict in dialogue', 'tension'
6. **VOICE** (mantido): 'voice', 'distinct'

#### Lições Aprendidas

1. **NLP requer semântica, não literais**
   - ❌ Ruim: `if 'subtext' in text`
   - ✅ Bom: `if 'subtext' or 'talk around' or 'stating' or ...`

2. **Mapeamento é crítico para todo pipeline**
   ```
   Mapeamento errado → Busca errada → Exemplos irrelevantes → Sistema inútil
   ```

3. **Testes isolados salvam tempo**
   - `test_core2_isolated.py`: 0.1s (sem LLM)
   - `test_triple_core.py`: 400s (com LLM)
   - Debugging: 30× mais rápido

4. **Validação automática é essencial**
   ```python

   assert examples > 20
   assert no "Structure" for dialogue analysis
   ```
