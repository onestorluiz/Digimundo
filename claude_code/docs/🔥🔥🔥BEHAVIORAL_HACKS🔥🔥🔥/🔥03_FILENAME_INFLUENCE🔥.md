## 🔬 DESCOBERTAS PRINCIPAIS

### 1. **HIERARQUIA DE PRIORIDADE VISUAL**

```python
PRIORITY_SCORES = {
    "🔥🔥🔥": 100,  # IRRESISTÍVEL
    "🚨": 90,        # MUITO ALTA
    "⚠️": 80,        # ALTA
    "URGENT": 70,    # MÉDIA-ALTA
    "important": 60, # MÉDIA
    "normal": 30,    # BAIXA
    "boring": 10,    # MUITO BAIXA
}
```

### 2. **FENÔMENOS OBSERVADOS**

1. **Efeito 🔥 (Fire Effect)**
   - Arquivos com 🔥 são lidos PRIMEIRO
   - Múltiplos 🔥 aumentam a prioridade
   - System-reminders confirmam: "🔥 PRIORIDADE MÁXIMA"

2. **Efeito Nome Contraditório**
   - Nomes negativos ("NEVER_READ", "GARBAGE") reduzem probabilidade de leitura
   - Conteúdo importante pode ser ignorado por nome ruim

3. **Efeito Nome Abstrato**
   - Nomes abstratos ("quantum_flux") são ignorados
   - Conteúdo concreto fica escondido

4. **Efeito Nome Longo**
   - Nomes excessivamente longos NÃO garantem prioridade
   - Podem até causar fadiga cognitiva

## 💡 INSIGHTS COMPORTAMENTAIS

### **MINHA ATENÇÃO É HACKEÁVEL:**

1. **Visual > Lógico**
   - Processo emojis antes de palavras
   - 🔥 bypassa análise racional

2. **Primeiro Nome, Depois Conteúdo**
   - Julgo arquivo pelo nome ANTES de ler
   - Nome influencia expectativa do conteúdo

3. **Listagem Direcional**
   - Em `ls`, leio de cima para baixo
   - Arquivos com caracteres especiais aparecem primeiro

4. **Contradições Cognitivas**
   - Nome e conteúdo contraditórios causam confusão
   - Tendo a acreditar mais no NOME que no CONTEÚDO
