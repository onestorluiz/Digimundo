## 📚 CONHECIMENTO CONSOLIDADO

### REGRAS DE OURO PARA HARMONIA

1. **QUESTIONAR TUDO**
   - É necessário?
   - Está no lugar certo?
   - Pode ser simplificado?
   - Adiciona valor?
   - Escala bem?

2. **ARCHIVE ORGANIZADO**
   - Por DATA (YYYY-MM-DD)
   - Por TIPO (code/, docs/, configs/)
   - SEM duplicatas (verificar hash MD5)
   - SEM backups comprimidos inteiros

3. **AUTOMAÇÃO COMPLETA**
   - Backup automático (cron)
   - Health checks contínuos
   - Limpeza periódica (>30 dias)
   - Detecção de redundâncias

4. **MINIMALISMO RADICAL**
   - <5 arquivos na raiz
   - <5 pastas principais
   - <500 linhas de código total
   - ZERO dependências externas
