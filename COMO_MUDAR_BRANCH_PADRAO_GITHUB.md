# 🔧 Como Mudar a Branch Padrão no GitHub

## 📋 Passo a Passo

### 1️⃣ Acesse as Configurações do Repositório

Abra seu navegador e vá para:
```
https://github.com/onestorluiz/Digimundo/settings
```

Ou navegue manualmente:
- Vá para: https://github.com/onestorluiz/Digimundo
- Clique na aba **"⚙️ Settings"** (canto superior direito)

---

### 2️⃣ Acesse o Menu de Branches

No menu lateral esquerdo, clique em:
```
🌿 Branches
```

Você verá uma seção chamada **"Default branch"**

---

### 3️⃣ Mude a Branch Padrão

1. Na seção **"Default branch"**, você verá algo assim:
   ```
   Default branch: main  ↔️
   ```

2. Clique no ícone de **setas duplas (↔️)** ou no botão de editar

3. Aparecerá uma lista de branches disponíveis

4. Selecione: **`github-main`**

5. Clique em **"Update"**

6. Confirme a mudança clicando em **"I understand, update the default branch"**

---

### 4️⃣ Verifique se Funcionou

Volte para a página inicial do repositório:
```
https://github.com/onestorluiz/Digimundo
```

Agora você deve ver:
- ✅ Todos os arquivos e pastas (Projeto_Digimundo, scripturemon, etc.)
- ✅ Branch selecionada: `github-main`
- ✅ Commits recentes visíveis

---

## ✅ Após Concluir

Depois de fazer isso:

1. **Claude Web** vai conseguir ver todo o repositório automaticamente
2. Você pode usar os prompts do `AI_SYMBIOSIS_WORKFLOW.md`
3. O repositório não vai mais aparecer como "vazio"

---

## 🔍 Verificação Rápida

Para ter certeza que funcionou, no GitHub você deve ver:

**Antes (branch main)**:
- Repositório aparece vazio ou com poucos arquivos
- Branch padrão: `main`

**Depois (branch github-main)**:
- ✅ Pasta `Projeto_Digimundo/` visível
- ✅ Pasta `scripturemon/` visível
- ✅ Pasta `claude_code/` visível
- ✅ Branch padrão: `github-main`

---

## 📝 Observação

Se você quiser manter `main` como branch padrão no futuro, terá que sincronizar ela com `github-main`. Mas por enquanto, deixar `github-main` como padrão é a melhor opção.
