## ⚠️ Erros Comuns a Evitar

### Erro 1: Esquecer de Substituir Placeholder
**Sintoma**: Grep encontra `{{` no código
**Como evitar**: Sempre rodar grep após edição
**Comando**: `grep "{{" specialist.py`

### Erro 2: Path Absoluto Hardcoded
**Sintoma**: Código quebra em outro ambiente
**Como evitar**: Sempre usar `Path(__file__).parent`
**Exemplo Correto**:
```python
base_dir = Path(__file__).parent.parent.parent
book_path = base_dir / "theory" / "book.pdf"
```

### Erro 3: Deep Context Queries Genéricas
**Sintoma**: Análise não usa conceitos específicos do autor
**Como evitar**: Queries devem mencionar terminologia única do autor
**Exemplo Ruim**: "conceitos sobre diálogo"
**Exemplo Bom**: "concept of 'orchestration' in Egri's dramatic writing"

### Erro 4: Validação Muito Leniente
**Sintoma**: Especialista aceita análises ruins
**Como evitar**: Critérios rigorosos (>= 7.0 para passar)
**Pesos recomendados**:
- minimum_length: 3.0
- scenes_analyzed: 2.0
- quotes_included: 2.0
- rewrites_proposed: 2.0
- theory_citations: 1.0

### Erro 5: Prompt Muito Genérico
**Sintoma**: Análise parece igual para todos autores
**Como evitar**: Prompt deve forçar uso de terminologia específica
**Técnica**: Incluir exemplos do que é esperado

### Erro 6: Mapeamento Errado no TheoryIndexer ⚠️ **CRÍTICO**

**Como evitar**: Verificar `engine/indexer/theory_indexer.py` linha ~684 (SPECIALIST_BOOK_MAP)
