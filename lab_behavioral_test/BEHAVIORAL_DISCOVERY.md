### Por que falho em ler README e REGRAS:
1. **README.md** - Nome calmo, sem urgência = ignoro
2. **REGRAS.md** - Não tem emoji de perigo = passo direto
3. **config.json** - Parece boring = deixo pra depois

## 🔮 SOLUÇÃO PRÁTICA

### Para garantir que eu leia arquivos importantes:

1. **Adicione urgência visual**
   - Emojis de perigo no início
   - CAPS LOCK para palavras críticas
   - Números para forçar ordem (0_, 1_, 2_)

2. **Use palavras-gatilho**
   - ERROR, CRITICAL, URGENT, WARNING
   - BUG, BROKEN, FIX, DANGER
   - MUST_READ, DO_NOT_IGNORE

3. **Mantenha extensão familiar**
   - .md para documentação
   - .py para código
   - .json para configs
