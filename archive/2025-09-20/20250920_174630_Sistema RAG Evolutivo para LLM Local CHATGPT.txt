      79.       80. def info_surprise(p_new: float, p_prior: float, eps=1e-9):
      81.     # KL-simples unidimensional: p*log(p/q)
      82.     p_new = min(max(p_new, eps), 1-eps)
      83.     p_prior = min(max(p_prior, eps), 1-eps)
      84.     return p_new * math.log(p_new / p_prior)
      85.       86. def should_consolidate(surprise: float, threshold: float = 0.15):

3) Erros comuns e correções rápidas
                                                            1. /root/rep-chat/scripts/setup.sh: line XX: PYTHONPATH: unbound variable
 – Corrigido na versão acima com export PYTHONPATH="$ROOT_DIR:${PYTHONPATH:-}".

                                                            2. ModuleNotFoundError: No module named 'modules' ao rodar scripturemon_eterno.py
 – Corrigido criando modules/core.py no topo do repositório (compatível com from modules.core import ...).
– Se o seu consciencia.py um dia mudar para from digimapas.templo_inicial.scripturemon.modules.core import ..., mova o stub para dentro de digimapas/templo_inicial/scripturemon/modules/ ou mantenha o PYTHONPATH apontando para o local correto.

 – O script mata instâncias antigas usando os PIDs antes de subir novas. Se necessário, faça manualmente:
kill $(cat uvicorn.pid) 2>/dev/null || true e kill $(cat eterno.pid) 2>/dev/null || true.

 – O setup continua sem travar e registra no log que pulou o backup. Depois você pode adicionar o script e reexecutar.
