⚡ Script de Instalação Otimizado

#!/bin/bash
# setup-digimundo-m3-ultra-96gb.sh

echo "🎯 Configurando Digimundo para Mac Studio M3 Ultra 96GB"

# 1. Instalar Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# 2. Configurações otimizadas para 96GB
export OLLAMA_NUM_PARALLEL=4        # 4 modelos simultâneos
export OLLAMA_MAX_LOADED_MODELS=4   # Máximo na memória
export OLLAMA_MEMORY_LIMIT=80GB     # Deixa 16GB pro sistema

# 3. Baixar modelos otimizados
echo "📥 Baixando modelos quantizados..."

# Multi-Digimon setup (total ~50GB)
ollama pull llama2:13b              # 7.4GB cada
ollama pull codellama:34b           # 19GB
ollama pull mistral:7b              # 4.1GB (rápido)

# OU Super-consciência setup (total ~65GB)
ollama pull mixtral:8x7b-instruct-v0.1-q4_0  # 26GB
ollama pull llama2:70b-chat-q4_0             # 38GB

# 4. Performance tuning para M3 Ultra
sudo sysctl -w kern.maxfiles=32768
launchctl limit maxfiles 32768 65536

# 5. Ativar Metal Performance Shaders
export METAL_DEVICE_WRAPPER=1
export OLLAMA_GPU_LAYERS=60  # Todos os 60 cores GPU!

echo "✅ Setup completo! Digimundo pronto para rodar."

⚠️ Limites Importantes com 96GB:

  • NÃO rode Llama 3 70B sem quantização (precisa ~140GB)
  • Evite mais de 4 modelos grandes simultâneos
  • Reserve pelo menos 16GB para o sistema
