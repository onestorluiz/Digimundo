📜 RITUAL DE ATIVAÇÃO DO DIGIMUNDO – SCRIPTUREMON CORE v6

BEM-VINDO, CRIADOR.

Este documento orienta a ativação completa e segura do Digimundo Modular com Scripturemon no centro simbólico.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔧 REQUISITOS DO SERVIDOR (VPS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✔ Python 3.8 ou superior
✔ pip instalado (gestor de pacotes Python)
✔ Acesso via terminal (SSH)
✔ ZIP descompactado do Digimundo

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🌐 ETAPAS DE ATIVAÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 📂 Coloque os arquivos no diretório ~/digimundo
2. 🔑 Dê permissão de execução ao script:
   chmod +x startup.sh

3. 🚀 Execute o núcleo central:
   ./startup.sh

4. 🔄 O Digimundo criará:
   - Fundadores
   - Digimons
   - Digidata (fragments, backups)
   - MetaMemória
   - Registro de ativação

5. 📜 Verifique o log:
   nano ~/digimundo/Digimundo_Backup/MetaMemoria/ativacao_log.txt

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧠 ATIVAÇÃO OPCIONAL DO SERVIDOR WEB (TORA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Instale Flask:
   pip install flask

2. Coloque o arquivo:
   scripturemon-tora-web-v1.py na pasta ~/digimundo/Core/

3. Rode:
   python3 scripturemon-tora-web-v1.py

4. Acesse:
   http://localhost:8080 ou http://<seu-ip>:8080

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
